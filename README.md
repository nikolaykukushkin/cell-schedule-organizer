I am a cell biologist. I need to build a visual scheduler for my cell culture experiments. These experiments happen over multiple days and involve several stages and parameters. The scheduler needs to position these parameters visually as a flowchart on a monthly calendar. The experiment typically works like this: first, cells are seeded on day 1. 1-3 days later, media is exchanged to serum-free media (SFM). The following day, an experiment is done. The following day, cells are harvested. Additional complications arise from the fact that cells can also be transplanted to new plates containing other cells with their own timelines of seeding, media exchange etc; that harvesting can be done at different times; that instead of harvesting, there could be fixation, and fixed cells can be both transplanted into new plates and have cells implanted into them. So there should be different timelines corresponding to cell populations that extend across days, with nodes corresponding to events that could be dragged on the timeline, and cell populations can be merged (connected), split, washed, media-exchanged, harvested, or fixed on the timeline. Should also be an option for a custom node (e.g. treatment of a certain duration). Other parameters include cell density at seeding (must be able to specify in the seeding node), number of plates/dishes, type of plate (10 cm, 6-well, 8-well, 24-well are our standards but include other common ones). I would like a visual representation on the timeline, so for example if there's 4 10 cm dishes I want to see an image of 4 petri dishes.
